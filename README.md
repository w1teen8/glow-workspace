# GLOW SPACE

Приватное рабочее пространство на двоих: разделы с заметкой, задачами и материалами и страница прогресса.

## Стек и почему он

| Что | Чем | Почему |
|---|---|---|
| Приложение | Next.js 16 (App Router) + TypeScript | Фронт и серверные эндпоинты в одном проекте и одном деплое |
| Хостинг | Любой Node-хостинг; готов конфиг для Render (бесплатный тариф) | Обычный `npm start`, HTTPS и деплой из GitHub у Render из коробки |
| База | Postgres на Neon, бесплатный тариф | Бесплатно и без срока (бесплатный Postgres у Render удаляется через 30 дней). Обычный SQL без ORM: таблиц шесть, схема в [db/schema.sql](db/schema.sql) |
| Вход | bcrypt + своя сессия в HTTP-only cookie | ~80 строк в [src/lib/auth.ts](src/lib/auth.ts), без внешних сервисов |
| Файлы | Прямо в Postgres, до 4 МБ | Не нужно отдельное хранилище, файлы отдаются только после входа |

Синхронизация — опрос `/api/state` раз в 5 секунд, пока вкладка открыта и видна. В фоне опрос останавливается, чтобы база Neon могла засыпать и не тратить бесплатные часы.

## Запуск локально

1. Создай проект на [neon.tech](https://neon.tech) и скопируй строку подключения (вариант *pooled*).
2. Настрой окружение:
   ```bash
   cp .env.example .env.local   # и заполни значения
   npm install
   npm run setup                # создаёт таблицы и аккаунт
   npm run dev                  # http://localhost:3000
   ```

`npm run setup` можно запускать повторно: данные не трогаются, пароль обновляется из `ADMIN_PASSWORD`, а старые сессии сбрасываются. Так же меняется пароль.

## Деплой на Render (когда понадобится)

1. На [render.com](https://render.com): *New → Blueprint* → выбрать этот репозиторий. Render прочитает [render.yaml](render.yaml).
2. Ввести `DATABASE_URL`, `PERSON_A`, `PERSON_B`. `ADMIN_*` на сервере не нужны: аккаунт создаётся командой `npm run setup` с твоего компьютера.
3. Дальше каждый `git push` в `main` деплоится сам.

На бесплатном тарифе Render сервис засыпает после 15 минут без запросов, и первое открытие после этого занимает около минуты. Пока сайт открыт, опрос не даёт ему уснуть.

## Где что лежит

```
db/schema.sql              схема базы
scripts/setup.mjs          создание таблиц и аккаунта
src/lib/sections.ts        список разделов — добавить или переименовать раздел здесь
src/app/api/*              серверные эндпоинты
src/components/*           интерфейс
src/app/globals.css        все стили; цвета и размеры — в начале файла
```

## Ограничения, о которых стоит знать

- **Файлы до 4 МБ.** Фото с телефона перед загрузкой уменьшаются в браузере до 2000 px, так что обычно они весят несколько сотен КБ. Бесплатный Neon даёт 0,5 ГБ на всё — это примерно тысяча фото. Если станет тесно, файлы переносятся в S3-совместимое хранилище: менять нужно только [src/app/api/items/route.ts](src/app/api/items/route.ts) и [src/app/api/files/[id]/route.ts](src/app/api/files/[id]/route.ts).
- **Заметку одновременно правят двое — сохранится последняя версия.** Пока человек печатает, изменения второго к нему не подтягиваются.
- **Защита входа**: 10 неудачных попыток с одного адреса или 50 со всех вместе блокируют вход на 15 минут.
